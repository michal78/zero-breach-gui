# Embedded CPython

CPython 3.13.16, Windows embeddable x64, from:
https://www.python.org/ftp/python/3.13.16/python-3.13.16-embed-amd64.zip

SHA-256:
97dae5274cc54867065e8d5a3226e48c35017ed332a0fdb0e27d5b5821961297

The archive digest matches the Python.org Sigstore bundle message digest:
https://www.python.org/ftp/python/3.13.16/python-3.13.16-embed-amd64.zip.sigstore

The extracted python.exe Authenticode signature was validated on the build machine; signer: Python Software Foundation. This is separate from a full Sigstore transparency verification, which was not performed. Build acquisition uses official HTTPS plus the pinned archive digest. Archive bytes are embedded unchanged. Every extracted runtime file is checked against the embedded archive before reuse.
